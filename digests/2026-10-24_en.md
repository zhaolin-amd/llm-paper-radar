#### Summary
Running 35B MoE models on consumer hardware faces a memory wall: at 4-bit quantization the model weighs 19.5GB, and naive SSD offloading fails because the next layer's expert selection cannot be known before the current layer finishes, preventing useful prefetch overlap. Edge0 introduces a prerouter—a per-layer head that predicts the next layer's routing one token ahead, allowing SSD reads to be issued in parallel with computation so that the prefetched expert set exactly equals the routed set. A recovery LoRA trained on the student path compensates for quality degraded by INT4 quantization and routing replacement. On a single 24GB GPU, Edge0 serves a 35B MoE at 20tok/s within 3GiB of peak active memory, staying within a few points of the fp16 teacher across five public benchmarks, with the full framework and checkpoints open-sourced.

- 🎯 Per-layer prerouter predicts next-layer expert routing one token ahead, enabling full compute-I/O overlap for SSD offloading

- 💡 Unmerged recovery LoRA trained on the student path jointly compensates INT4 quantization loss and routing replacement error
- 🔧 Framework, checkpoints, and adapters are fully open-sourced; supports both 35B and 8B model tiers

#### Summary
KV cache memory capacity and bandwidth are key bottlenecks for long-context LLM inference; existing lossless KV compression methods still decompress to GPU memory before attention, leaving repeated KV reads unresolved. ZipFusion co-designs the compression format and attention kernel so that attention consumes the compressed KV cache directly, reconstructing original values in registers via simple bit operations with no separate decompression pass. A memory manager redistributes compression-freed memory across layers to increase batch concurrency. #### Summary
Existing KV-cache quantization methods are designed for standard attention and fail to account for what MLA actually stores—a compressed latent and a narrow positional key—leading to accuracy degradation at low bit widths. RAQ-MLA analyzes how quantization error in each cached tensor propagates to the attention output: the latent primarily affects values, while the positional key dominates the attention score. Based on this role analysis, RAQ-MLA fits a separate invertible transform to each tensor using role-appropriate error objectives (attention-weighted value error for the latent; score perturbation for the positional key). Without any training, RAQ-MLA quantizes the full MLA cache to approximately 2.5 bits per element, achieving a 6.5× theoretical KV-cache capacity increase while remaining nearly lossless on reasoning and coding tasks across four MLA models.

- 🎯 Role-aware invertible transforms applied separately to MLA's latent and positional key tensors based on their distinct error-propagation roles
- 💡 Latent quantization targets attention-weighted value error; positional key targets score perturbation—a novel per-tensor objective design
- 📊 Training-free PTQ quantizes full MLA cache to ~2.5 bits/element, yielding 6.5× theoretical KV-cache capacity increase
- ⚠️ No end-to-end latency results reported; practical deployment requires kernel support for non-standard bit widths
