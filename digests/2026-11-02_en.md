#### Summary
Existing block-scaled LUT quantization formats (NF4, BOF4, NVFP4, etc.) rely on fixed grids that are suboptimal across bit-widths. SHq introduces a closed-form parameterized grid family with two degrees of freedom: a companding strength α that interpolates level spacing from uniform to floating-point-like, and an asymmetry offset c that allows the sign bit of the FP8 block scale to select between a grid and its mirror image, up to doubling distinct values per block. Evaluated on five models from 3B to 35B parameters (including MoE) at 2–6 bits using RTN and GPTQ, SHq achieves the lowest KL divergence in every setting at 3 and 4 bits, outperforms the best fixed grid by up to 34%, and reduces NVFP4's KL divergence by 41–67% at 4.5 bits per weight while improving downstream accuracy.

- 📊 At 4.5 bits/weight, reduces NVFP4 KL divergence by 41–67% and improves downstream accuracy

#### Summary
Inference cost of LLMs constrains coding agent deployment, and quantization is a standard compression approach, yet its behavioral effects on agents that execute and revise code remain poorly understood. This work compares BF16 against 4-bit AWQ and GPTQ for Qwen2.5-Coder-Instruct (7B, 14B, 32B) and Devstral-Small-2507 (24B) on OJBench across three seeds. No statistically significant accuracy drop is detected for any model, but behavioral shifts are substantial: AWQ reduces Qwen-7B one-shot solves from 17 to 0 while increasing loop-based solves from 10 to 25, and Devstral's failures shift markedly from runtime errors toward wrong answers and timeouts under quantization. The findings argue that quantization robustness for coding agents must be evaluated through solution trajectories, tool-use patterns, and failure profiles beyond final accuracy.

- 📊 No statistically significant accuracy loss for any model, yet AWQ drops Qwen-7B one-shot solves from 17 to 0 and raises loop-based solves from 10 to 25
- 📊 Devstral's failure profile shifts significantly from runtime errors to wrong answers and timeouts after quantization; Qwen-32B compilation errors rise slightly
- 💡 Final accuracy alone is insufficient — solution trajectories, tool-use patterns, and failure modes must be assessed for quantization robustness in coding agents
