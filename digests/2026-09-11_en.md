#### Summary
Low-bit quantization of LLM attention modules introduces large errors, and existing smoothing-based methods inadequately handle outliers. HyQuant is a hybrid-precision quantization framework that retains vertical-line tokens and a local sliding window in full precision during the Prefill stage while quantizing the remaining context to low bits. In the Decode stage, the same principle is applied to KV-cache compression, with KV dequantization fused into the attention computation to improve memory and hardware efficiency. Experiments across diverse tasks, models, and datasets demonstrate nearly lossless accuracy with a simple design, and code is publicly available.

Block removal compression of LLMs—selecting which Transformer blocks to delete—is formulated as a constrained binary optimization (CBO) problem mapped to an Ising glass physical system, whose energies serve as a proxy for downstream performance. This enables efficient ranking of a large number of candidate block-removal configurations, including non-consecutive deletions that SOTA methods overlook.
