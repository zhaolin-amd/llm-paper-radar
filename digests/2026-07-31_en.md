#### 🧭 Why this paper
**KV cache compression** · topic 5/5 · practicality 4/5 · composite 9/10 · ResKV proposes splitting the KV cache into an exact main cache and a compact residual cache, reconstructing the contributions of evicted tokens by restoring both numerator and denominator mass within the same softmax normalization. The method is validated on LongBench and RULER, two established long-context benchmarks, covering query-aware and query-agnostic settings across multiple backbones and cache budgets, making it a core KV cache compression work. The algorithm is concise (main cache + compact residual cache + dynamic gate), requires no gradient-based training, has low calibration cost, and explicitly preserves peak memory and decode throughput, yielding strong deployment practicality (rated 4).

#### Summary
KV cache eviction methods permanently discard unselected tokens, removing their aggregate attention contribution, while merging-based alternatives preserve more information but perturb retained keys and values. ResKV formulates the information omitted by eviction as residual statistics in both the numerator and denominator of softmax attention, then divides a fixed KV budget into an exact main cache and a compact residual cache that reconstructs these contributions. Main-cache tokens and residual entries participate in the same softmax normalization, restoring both numerator and denominator mass rather than applying a post-hoc correction. A construction-time validation proxy allocates residuals per layer and KV head, while a decode-time dynamic gate adjusts residual contributions per query; comprehensive evaluations on LongBench and RULER show broad improvements under the same KV budget while preserving peak memory usage and long-context decode throughput.

- 🎯 Splits a fixed KV budget into an exact main cache and a compact residual cache that jointly restores softmax numerator and denominator mass.
- 💡 Construction-time validation proxy allocates residuals per layer/KV head; decode-time dynamic gate adapts contributions per query.
- 📊 Evaluated on LongBench and RULER across query-aware and query-agnostic settings, multiple backbones, cache budgets, and compression baselines, achieving broad gains at equal KV budget.
- 🔧 Preserves peak memory usage and long-context decode throughput; requires no gradient-based training.
