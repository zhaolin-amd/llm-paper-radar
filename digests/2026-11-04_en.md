#### Summary

#### 🧭 Why this paper
**KV cache compression** · topic 4/5 · practicality 4/5 · composite 8/10 · SEED proposes two complementary compressions for hybrid LLMs: (1) shallow prefill via emitter layers that write deep memories from a shallow anchor, skipping up to 37% of layers; (2) low-rank recurrent state representation (sink + low-rank working memory). #### Summary
Hybrid language models maintain per-layer KV caches or fixed-size recurrent states, causing prefill and decode to consume more compute and high-bandwidth memory than necessary. SEED exploits two properties of trained hybrids: (1) writing a deep layer's memory requires far less computation than reading it, so trained 'emitter' modules write deep memories from a shallower anchor layer's residual stream, letting all prompt tokens except the last pass through as few as 63% of layers; (2) recurrent states exhibit a 'state sink'—most energy lies in a rank-one term along a fixed per-head direction—so each state is stored as its sink plus low-rank factors, with open-loop compression error provably bounded independently of the number of compressions. - 💡 Recurrent states decomposed into rank-one sink + low-rank working memory; periodic recompression error is provably bounded regardless of compression count
- 📊 Nearly lossless on 11 official exams across five 30B–300B+ hybrid models; 1.2–1.4× per-GPU throughput on NVIDIA GB300 for Qwen3.8-Flash-Next
- 🔧 Frozen weights, zero calibration data, no attention cache compression; exact update rules derived for Gated DeltaNet, Kimi Delta Attention, and Mamba-2
