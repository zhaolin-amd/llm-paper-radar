#### Summary
Long-context LLM serving is bottlenecked by reading the full KV cache at every decode step. LOCKS assigns each page its own spectral summary (~1/10 the cache size), estimates per-page attention mass via log-sum-exp, and attends only the top-ranked pages—without reading any candidate keys or values during selection. At a 2048-token budget, LOCKS matches FullKV aggregate quality at 100K+ context while attending ~2% of tokens, halving per-token decode latency (2.0× at 1M tokens). It ships as a drop-in plugin for unmodified vLLM with full CUDA graph support, requiring no retraining or calibration data.

#### Summary
KV cache becomes a growing bottleneck in long-context LLM inference, and existing low-rank compression methods typically treat Key and Value caches uniformly while using fixed attention-head groupings. DynaCalKV addresses this by dynamically grouping attention heads for the Key cache based on Centered Kernel Alignment (CKA) similarity and adaptively allocating rank budgets per group under a parameter constraint, while adopting the ReCalKV offline calibration approach for the Value cache. Experiments on three instruction-tuned LLMs show reduced Key cache parameter counts with competitive accuracy. The method is found to be most effective for Multi-Head Attention (MHA) models, while requiring more conservative application to Grouped-Query Attention (GQA) models in long-context settings.
