#### Summary
Running 35B-class MoE models on consumer hardware (single 24GB GPU + SSD) is bottlenecked by weight memory: at 4-bit the model occupies 19.5GB, and naive SSD offloading cannot prefetch layer N+1's experts early enough because their routing depends on layer N's output. Edge0 addresses this with a prerouter—a per-layer head that predicts the next layer's routing one token ahead—so expert weights can be streamed from SSD in parallel with compute, with the prefetched set exactly matching the routed set. An unmerged recovery LoRA trained on the student path compensates for quality loss from both INT4 quantization and routing replacement, achieving 20tok/s on a single 24GB machine with only 3GiB peak active memory while staying within a few points of the fp16 teacher across five public benchmarks.

- 🎯 Per-layer prerouter predicts next-layer routing one token ahead, enabling SSD reads to fully overlap with compute
