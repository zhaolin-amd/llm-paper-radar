#### Summary
MoNe attaches a lightweight modular neural memory to any frozen pretrained Transformer, enabling long-context inference without retraining. During preprocessing, it performs test-time learning with layer-localized gradient updates over fixed-size context segments using fast-weight neural memory networks; at inference, keys and values are generated solely from query tokens with no context re-reading. This two-phase design yields O(N) preprocessing and O(1) query cost, with peak GPU memory independent of context length N. At 128K tokens, MoNe reduces both compute and peak GPU memory by approximately 80% compared to ICL, with only 6.4% parameter overhead, and generalizes beyond the backbone's native window on RULER benchmarks where ICL degrades sharply.

- 🎯 Attaches modular neural memory to frozen Transformers; test-time learning updates fast weights per context segment; inference generates KV from query tokens only.
- 📊 At 128K tokens, reduces compute and peak GPU memory by ~80% vs. ICL with only 6.4% parameter overhead.
- 💡 Achieves O(N) preprocessing + O(1) query cost; peak GPU memory does not grow with context length N.
- 📊 Generalizes to context lengths beyond the backbone's native window; strong results on RULER needle-in-a-haystack and word extraction where ICL degrades sharply.

#### Summary
Autoregressive LLMs suffer from sequential decoding latency and poor GPU utilization; speculative decoding reduces this but existing draft models remain autoregressive. DFlash introduces a lightweight block diffusion model as the drafter, generating draft tokens in a single parallel forward pass while conditioning on context features extracted from the target model to achieve high acceptance rates. Across diverse models and tasks, DFlash delivers over 6x lossless speedup and up to 2.5x higher speedup than the state-of-the-art EAGLE-3.

- 🎯 Replaces autoregressive drafting with a block diffusion model that generates multiple tokens in one forward pass
- 💡 Draft model is conditioned on context features from the target LLM, improving draft quality and acceptance rates
- 📊 Achieves over 6x lossless acceleration across models and tasks; up to 2.5x faster than EAGLE-3
- ⚠️ Requires training a dedicated diffusion draft model, increasing integration complexity over standard speculative decoding

#### 📎 Related methods / baselines
