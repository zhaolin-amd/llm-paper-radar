#### Summary
MoE inference on consumer hardware is bottlenecked by weight memory: a 35B model occupies 19.5GB at 4-bit, and sparsity reduces compute per token but not memory footprint. Naive SSD offloading fails because expert selection for layer N+1 cannot begin until layer N's output is available, leaving no compute to hide the read latency behind. Edge0 introduces a prerouter—a per-layer head that predicts the next layer's routing one token ahead—so SSD reads are fully overlapped with current-layer compute, with the staged expert set exactly matching the routed set. A recovery LoRA, trained on the student path (INT4 + routing replacement), compensates for both quantization and routing-substitution quality loss. On a single 24GB GPU, Edge0 delivers 35B MoE inference at 20 tok/s within 3GiB of peak active memory, staying within a few points of the fp16 teacher across five public benchmarks.
