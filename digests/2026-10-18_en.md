#### Summary
MoE inference on consumer hardware is bottlenecked by weight memory: a 35B model at 4-bit is 19.5GB, and sparsity reduces compute but not the bytes to be loaded. Naive SSD offloading fails because layer N+1's expert selection cannot begin until layer N's output is available, leaving no time to hide read latency behind compute. Edge0 introduces a prerouter—a per-layer lightweight head that predicts the next layer's routing one token ahead and uses that prediction as the actual routing decision, enabling streaming prefetch of expert weights from SSD. A recovery LoRA, trained on the student (prerouter) path and kept unmerged, compensates for quality loss from both INT4 quantization and routing replacement. On a single 24GB machine, Edge0 serves a 35B MoE at 20tok/s within 3GiB of peak active memory, staying within a few points of the fp16 teacher across five public benchmarks.

- 🎯 Prerouter predicts next-layer routing one token ahead and uses prediction directly as routing, enabling SSD expert prefetch
- 💡 Unmerged recovery LoRA trained on the student path compensates for both INT4 quantization and routing-replacement accuracy loss
- 📊 35B MoE (INT4 = 19.5GB) served at 20tok/s on a single 24GB GPU with only 3GiB peak active memory
- 🔧 Framework, checkpoints, and adapters are fully open source; same framework supports an 8B tier

#### Summary
Ternary LLMs like BitNet b1.58 face a mixed-precision matrix multiplication (mpGEMM) bottleneck during edge inference. Bitnet.cpp addresses this with two core mpGEMM solutions: Ternary Lookup Table (TL), which overcomes spatial inefficiencies of bit-wise methods, and Int2 with Scale (I2_S), which guarantees lossless inference, both achieving sub-2-bits-per-weight execution. Experiments show up to 6.25x speedup over full-precision baselines and up to 2.32x over low-bit baselines. The system is open-sourced and requires no calibration or retraining.

- 🎯 Proposes TL and I2_S mpGEMM kernels enabling sub-2-bit, lossless ternary LLM edge inference
- 📊 Achieves up to 6.25x speedup over full-precision and up to 2.32x over low-bit baselines
- 💡 TL extended to element-wise lookup table (ELUT) with theoretical and empirical evidence for low-bit LLMs
- 🔧 No calibration or retraining required; open-source and ready for direct edge deployment
