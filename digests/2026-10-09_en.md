#### Summary

#### 🧭 Why this paper
**KV cache compression** · topic 4/5 · practicality 4/5 · composite 8/10 · ReplaySSM targets the recurrent state I/O bottleneck in SSM (Mamba-2 / Gated DeltaNet) hybrid models. By introducing an input replay buffer, state writes are decoupled from per-step computation into periodic checkpoint updates, and a dual-precision checkpoint scheme (low-precision for output computation, high-precision for recurrent updates) effectively reduces state memory traffic and limits quantization error propagation. The method is implemented in vLLM and validated on 120B-class hybrid models with 1.2–1.47× speedup and ~1.8× speculative-decoding throughput. Although no standard benchmarks such as MMLU/GSM8K are reported, the quantization precision-separation mechanism and system-level throughput data are clearly defined, with a concise algorithm and a clear deployment path. topic_relevance is capped at 4 due to the absence of standard downstream benchmark numbers; practicality is rated 4 given vLLM integration, zero calibration cost, and concrete speedup figures.

#### Summary
SSM hybrid models must read and write a fixed-size recurrent state at every decoding step, creating high state I/O overhead, low arithmetic intensity, costly speculative-decoding rollbacks, and compounding quantization error. ReplaySSM unrolls the recurrence to represent state as a periodic checkpoint plus a buffer of recent SSM inputs, decoupling output computation from checkpoint updates; checkpoints are refreshed periodically, reducing dominant state memory traffic by roughly half. Keeping recent inputs makes speculative rollback a buffer-pointer operation, and a dual-precision checkpoint scheme—low-precision for output computation, high-precision for recurrent updates—prevents quantization rounding errors from propagating into subsequent state updates. Implemented in vLLM for Mamba-2 and Gated DeltaNet, ReplaySSM achieves 1.20–1.47× speedup over a tuned vLLM baseline at batch size 256 and delivers ~1.8× the speculative-decoding throughput on two 120B-class hybrid models.

- 💡 Dual-precision checkpoint: low-precision copy for output computation, high-precision copy for recurrent updates, blocking quantization error propagation
- 🔧 Implemented in vLLM for Mamba-2 and Gated DeltaNet; speculative rollback reduced to a buffer-pointer operation
