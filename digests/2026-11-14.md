#### 摘要
LLM 推理服务中，KV cache 内存因碎片化和冗余复制而大量浪费，严重限制了可并发的 batch size。PagedAttention 借鉴操作系统虚拟内存与分页机制，将 KV cache 分割为固定大小的 block，实现按需分配与跨请求灵活共享。基于此构建的 vLLM 系统将 KV cache 内存浪费降至近零，与 FasterTransformer 和 Orca 等当时最优系统相比，在相同延迟下吞吐量提升 2–4×。

- 🎯 PagedAttention 将 KV cache 拆分为固定 block，支持非连续内存分配与跨请求共享
- 📊 相比 FasterTransformer / Orca，vLLM 在相同延迟下吞吐量提升 2–4×
- 💡 near-zero KV cache 内存浪费，支持更大 batch size 与更复杂的 decoding 算法
- 🔧 适用于更长序列、更大模型场景，收益更显著；代码已开源
