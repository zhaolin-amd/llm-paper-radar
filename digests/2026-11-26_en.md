#### Summary
Real-time autoregressive video generators struggle to maintain consistent characters, objects, and scenes across long interactive stories. Agentic LongLive introduces an asynchronous agentic memory system where a memory agent on separate GPUs reads only revealed prompts, maintains per-entity text states and images, and prefills a composed global and per-shot memory image into the generator's attention sink before each shot—without reading back generated video or blocking the stream. Memory decisions are made by a small language model trained with reinforcement learning, using an image reward calibrated from downstream video outcomes. On the new LongStory-Online benchmark (25 stories, 857 shots), the system improves LongLive-2.0's persistent-state accuracy by 26.3 points, protagonist identity by 44.9, and revisited-place consistency by 40.4, with ~1% extra generation time, streaming faster than real time at 34.3 FPS on a single 8xB200 node in BF16.

- 🎯 Memory agent on separate GPUs asynchronously maintains entity text states and images, injected via attention sink prefill with zero generation blocking

- 📊 Streams at 34.3 FPS on one 8xB200 node in BF16, sustaining image quality across 14-minute stories
- 💡 Small LM memory policy trained with RL; reward signal calibrated from downstream video outcomes, no advance script access required

#### Summary
LLM deployment is constrained by memory and computation demands, and maintaining fidelity in the sub-1-bit regime is an open challenge. LittleBit represents weights through low-rank latent matrix factorization followed by binarization of the factors, and counters information loss with a multi-scale compensation mechanism spanning row, column, and latent dimensions. Training is enabled by Dual Sign-Value-Independent Decomposition (Dual-SVID) for QAT initialization and Residual Compensation to reduce approximation error. At 0.1 BPW, LittleBit compresses Llama2-13B to under 0.9 GB (~31× memory reduction) and outperforms leading methods operating at 0.7 BPW on Llama2-7B, with a theoretical 11.6× inference speedup over FP16.
