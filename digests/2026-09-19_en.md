#### Summary
MoE inference on consumer hardware is bottlenecked by weight memory: a 35B MoE model occupies 19.5GB at 4-bit, and naive SSD offloading fails because expert weights for layer N+1 cannot be prefetched before layer N completes. Edge0 introduces a prerouter—a per-layer head that predicts the next layer's expert routing one token ahead—so SSD reads are fully pipelined behind compute and the predicted expert set equals the routed set with no drops. A recovery LoRA trained on the student path (INT4 quantization + routing replacement) recovers the resulting quality loss. On a single 24GB machine, Edge0 serves a 35B MoE at 20tok/s within 3GiB peak active memory, matching within a few points of its fp16 teacher across five public benchmarks.
