#### Summary
MoE inference on consumer hardware is bottlenecked by weight memory: a 35B model occupies 19.5GB at 4-bit, and sparsity reduces per-token compute but not the bytes that must be stored. Naive SSD offloading fails because expert selection for layer N+1 depends on layer N's output, preventing early SSD reads. Edge0 introduces a prerouter—a per-layer head that predicts the next layer's routing one token ahead—so the staged expert set exactly matches the routed set and no experts are dropped. An unmerged recovery LoRA, trained on the student inference path, compensates quality loss from both INT4 quantization and routing replacement. On a single 24GB GPU, Edge0 achieves 20tok/s for a 35B MoE within 3GiB of peak active memory, approaching fp16 teacher quality across five public benchmarks.

- 🎯 Prerouter predicts next-layer expert routing one token ahead, enabling SSD reads to overlap with compute and hide offloading latency
- 🎯 Recovery LoRA trained on the student path jointly compensates INT4 quantization loss and routing-replacement error
- 📊 35B MoE at 20tok/s on a single 24GB GPU with only 3GiB peak active memory, near fp16 teacher on five benchmarks
