- 📊 混合4/8-bit PACE在4B-35B hybrid模型上接近8-bit DAMP性能，显存约为其2/3
- 📊 纯4-bit PACE在等显存条件下得分高于Q-Mamba，同时保留chunked decoding加速

Looped 架构通过重复使用同一 block 提升模型质量，但每次 recurrence 生成独立 KV-cache 导致内存线性增长。本文系统研究了如何使 looped 模型具备 KV-shareability：第一阶段在预训练中引入 stochastic depth，使各 recurrence 的表示通过压缩残差动态收敛至公共极限；第二阶段提出 BeNice! post-training 方法，将最终 recurrence 的 KV-cache 广播至第一 recurrence 并微调使其产生兼容残差，同时保持原始模型质量。BeNice! 可与 multi-latent attention、Kimi delta attention 及 FP8/MXFP8/NVFP4 KV 量化等方法正交组合，在低内存长上下文推理场景下 cache hit rate 提升最高 31.4%、吞吐量提升最高 23.6%、p90 TTFT 降低最高 83.6%。

- 🎯 两阶段方法：预训练引入 stochastic depth 促使 recurrence 表示收敛，BeNice! post-training 广播最终 KV-cache 并微调兼容性
- 💡 首次系统揭示 KV-shareability 的产生机制：压缩残差动态驱动各 recurrence 表示趋向公共极限
- 📊 低内存长上下文推理：cache hit rate +31.4%，throughput +23.6%，p90 TTFT 降低 83.6%
- 🔧 与 multi-latent attention、Kimi delta attention、FP8/MXFP8/NVFP4 KV 量化正交可组合

#### 摘要
Speculative decoding 在长输出场景下需要维护大 KV cache，对 draft model 使用 selection-based KV cache 压缩时，随着输出长度增长，预填充阶段选出的 KV 条目逐渐失效（decode staleness），导致 draft 质量下降。RIFT 提出一族 selection-based 压缩策略，在 prefill 信息与近期生成 token 之间动态平衡，并引入 adaptive KV refresh 机制以减少 refresh 过程中的 score 计算开销。配合基于 sparse attention mask 的 compressibility training，RIFT 使 Qwen3.5-4B（为 Qwen3.5-122B 起草）在 32K 输入、4K 输出、8K KV cache 预算下保留超过 98% 的 full-cache acceptance length。

- 🎯 RIFT 在 selection-based KV cache 压缩中平衡 prefill 信息与近期 token，定期 refresh KV selection 以对抗 decode staleness
- 💡 Adaptive KV refresh 策略减少 score 计算次数，在保持 draft 质量的同时降低 decode 侧额外延迟
- 🔧 Compressibility-driven drafter training 基于 sparse attention mask 对 draft model 进行微调，提升其在压缩 KV cache 下的质量
- 📊 结合 compressibility training 后，Qwen3.5-4B 在 32K 输入、4K 输出、8K KV cache 预算下保留 >98% full-cache acceptance length
