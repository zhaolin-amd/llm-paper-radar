#### 摘要
自回归 LLM 的顺序解码导致高推理延迟和低 GPU 利用率。DFlash 提出了一种 speculative decoding 框架，使用轻量级 block diffusion 模型作为 drafter，在单次前向传播中并行生成 draft tokens，并以目标模型提取的 context features 作为条件输入，从而提升 draft 质量和 acceptance rate。实验表明，DFlash 在多种模型和任务上实现超过 6x 的无损加速，比当前最优方法 EAGLE-3 快最多 2.5x。

- 🎯 用轻量 block diffusion 模型替代自回归 drafter，单次前向传播生成全部 draft tokens
- 💡 以目标模型提取的 context features 条件化 draft 模型，提升输出质量和 acceptance rate
- 📊 在多模型多任务上实现 >6x 无损加速，比 EAGLE-3 提速最多 2.5x
- ⚠️ 需专门训练轻量级 block diffusion 草稿模型，增加部署准备成本
