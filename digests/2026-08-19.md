#### 🧭 为什么推送这篇
**KV cache 压缩** · topic 0/5 · practicality 0/5 · composite 0/10 · MoNe的主要贡献是为frozen pretrained Transformer附加神经记忆模块，属于一种attention架构/memory机制的改造，而非对固定预训练模型KV cache的后处理压缩（量化/驱逐/低秩分解）。其fast-weight neural memory需要test-time learning（即test时对每个context segment执行梯度更新），这与KIVI/KVQuant/H2O等post-hoc KV cache压缩方法的范式完全不同。按照规则，基于attention机制重设计（如GQLA等）属于hard_gate范畴；该方法改变了KV生成方式而非压缩已有KV cache，不符合kv_cache bucket定义，也不适合其他任何bucket，因此hard_gate。

#### 摘要
MoNe 为任意 frozen pretrained Transformer 附加一个轻量模块化神经记忆，无需重新训练即可支持长上下文推理。预处理阶段通过 test-time learning 对固定大小的上下文分段执行快速权重神经记忆网络的层局部梯度更新；推理阶段仅由 query tokens 生成 keys 和 values，不再重读上下文 tokens。该两阶段设计使预处理开销为 O(N)、查询开销为 O(1)，且 peak GPU memory 不随上下文长度增长；在 128K tokens 下，MoNe 相比 ICL 将计算量和 peak GPU memory 均降低约 80%，参数开销仅 6.4%。

- 🎯 为 frozen Transformer 附加模块化神经记忆，test-time learning 对每段 context 执行层局部梯度更新，推理时仅用 query 生成 KV。
- 📊 128K tokens 下，compute 和 peak GPU memory 相比 ICL 降低约 80%，参数开销仅 6.4%。
- 💡 实现 O(N) 预处理 + O(1) 查询的复杂度解耦，peak GPU memory 不随上下文长度 N 增长。

#### 摘要
自回归LLM推理因顺序解码导致高延迟与低GPU利用率，speculative decoding虽能缓解但draft阶段仍为自回归序列生成。DFlash引入轻量block diffusion模型作为draft模型，利用单次前向传播并行生成草稿token，同时将目标模型提取的上下文特征注入draft模型以提升接受率。实验显示DFlash在多种模型和任务上实现超6x无损加速，比当前最优方法EAGLE-3快最高2.5x。

- 🎯 以轻量block diffusion模型替代自回归draft，单次前向传播并行生成多个草稿token
- 💡 draft模型从目标模型提取上下文特征作为条件，提升draft质量与接受率
- 📊 多模型多任务下实现超6x无损加速，最高比EAGLE-3快2.5x
- ⚠️ 需训练专用diffusion draft模型，集成复杂度高于传统speculative decoding
