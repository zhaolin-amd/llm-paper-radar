#### 摘要

#### 🧭 为什么推送这篇
**Low-bit（≤ 2-bit）** · topic 4/5 · practicality 3/5 · composite 7/10 · FluxBin提出了一种基于LUT的极低比特（binary bases）LLM推理方案，包含Decoupled Row-Column Binary Decomposition和Hessian引导的混合基分解算法，以及配套的CUDA kernel（Virtual Columnar Mapping + Scale Fusion）。方法为algorithm-kernel co-design，属于low_bits桶。实测在70B模型上达到5.92x加速和10.19x能效提升，代码已开源，部署路径清晰（单A100）。不足在于：(1) abstract未明确说明使用了哪些标准下游benchmark（MMLU、GSM8K等），accuracy评估依据不完整，topic_relevance压至4；(2) kernel设计有一定复杂度（LUT构建、Virtual Columnar Mapping），需要自定义CUDA，practicality不能给满分，定为3。总体是有价值的低比特推理工作，值得追踪。

#### 摘要
二值量化在理论上提供极高压缩率，但现有方法因依赖浮点运算或运行时反量化，无法充分发挥加速潜力。FluxBin 提出 algorithm-kernel co-design：算法层面引入 Decoupled Row-Column Binary Decomposition 提升表示能力，并用 Hessian 引导的显著性感知混合基保留关键信息；kernel 层面实现基于 LUT 的 Scale Fusion 和 Virtual Columnar Mapping，将稀疏显著性矩阵转化为密集执行。在多种模型架构上实现最高 5.92× 加速和 10.19× 能效提升，支持 70B 规模模型在单张 A100 GPU 上部署，内存压缩 4×。

- 🎯 算法：Decoupled Row-Column Binary Decomposition + Hessian 引导混合基，提升极低比特表示能力并兼顾硬件效率
- 🔧 Kernel：LUT Building with Scale Fusion + Virtual Columnar Mapping，消除浮点开销，将稀疏矩阵转为密集执行
- 📊 最高 5.92× 加速、10.19× 能效提升，70B 模型可在单张 A100 上以 4× 内存压缩部署
- 💡 精度与重度微调方法相当，无需额外 fine-tuning
