#### Summary
Low-bit attention inference typically computes softmax in high precision and then quantizes the probability block before low-bit PV multiplication, creating a producer-consumer precision mismatch. EFQ-Softmax eliminates this by directly mapping shifted attention scores to block-scaled E2M1 operands: for each microscaling block, an exponent-only scale is selected from the local maximum, scores are mapped to a normalized residual domain, and nonnegative E2M1 probability codes are generated via a single affine rule, used consistently in both the PV numerator and P·1 denominator updates. The FlashAttention-style row-maximum update, historical rescaling, high-precision accumulation, and final normalization are preserved unchanged. EFQ-Softmax raises the Qwen3-8B seven-task mean from 0.6749 (MXFP4) to 0.6773 and the Qwen3-VL nine-task mean from 0.7826 to 0.8000, while reducing fused kernel vector-stage latency by 40.33% on average across 16K–128K sequence lengths on the A5 vector unit.

- 📊 Qwen3-8B seven-task mean improves from 0.6749 (MXFP4) to 0.6773; Qwen3-VL nine-task mean from 0.7826 to 0.8000
- 📊 Fused probability-generation kernel vector-stage latency reduced by 40.33% on average (16K–128K) on A5 vector unit
- 💡 Calibration-free and data-independent; fully compatible with FlashAttention row-maximum updates and high-precision accumulation

#### Summary
Large Reasoning Models (LRMs) suffer from linearly growing KV caches during extended Chain-of-Thought generation, creating severe GPU memory bottlenecks. Existing KV cache compression methods use recent queries as proxies for future attention, but this assumption breaks down in long-horizon reasoning where Thought Revisiting Tokens (TRT) re-attend to distant early context. BeaconKV discovers that TRT-corresponding queries cluster into a small number of similarity groups in embedding space, and maintains compact beacon queries—one per global query cluster—to anticipate which KV pairs will be revisited without storing the full query history. Evaluated across four open-source LRMs and diverse reasoning benchmarks, BeaconKV achieves up to 5.8× memory reduction and over 4.3× throughput improvement while nearly preserving full-cache accuracy.

- 🎯 Maintains compact beacon queries as global cluster representatives to predict KV pair revisits, training-free
- 💡 Identifies that TRT-corresponding queries form a small number of similarity clusters in embedding space
- 📊 Up to 5.8× memory reduction and over 4.3× throughput gain with near-full-cache accuracy
- 🔧 No training required; only query cluster representatives maintained at inference time, directly deployable

#### Summary
Depth pruning removes complete Transformer blocks to reduce LLM inference cost, but existing forward-free approaches score each block independently and miss inter-layer redundancy. WRP (Weight-Redundancy Pruning) estimates this redundancy purely from checkpoint weights by comparing attention output and MLP down-projection matrices across layers, combining pairwise weight similarities with relative projection-scale information to build an all-pairs similarity matrix that guides block grouping and selection. No calibration data or model forward passes are required. Across multiple pruning settings, model families, and downstream tasks, WRP consistently outperforms existing forward-free magnitude pruning and approaches the performance of activation-based methods.

- 🎯 Compares attention output and MLP down-projection weights across layers from checkpoints to build an all-pairs similarity matrix for block selection
- 💡 Combines pairwise weight similarity with relative projection-scale information to capture inter-layer redundancy rather than scoring blocks in isolation
- 📊 Consistently outperforms forward-free magnitude pruning and approaches activation-based methods across multiple model families and downstream tasks
- 🔧 Fully data-free: requires no calibration data or model forward passes, minimizing deployment overhead
