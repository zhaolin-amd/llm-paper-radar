#### 摘要
Coding agent 服务面临缺乏真实 workload 数据的挑战，现有公开 trace 和 benchmark 无法反映日常多 agent、多模型的实际使用模式。本文收集并发布了约 4,300 个 coding-agent session（涵盖 ~35 万 LLM steps 和 ~43 万 tool calls），数据来源为 Claude Code 和 Codex 的日常真实使用。分析揭示了长自主循环、长上下文短输出、重尾 tool call 分布、高但不完美的 prefix cache 命中率等关键特征，并据此提出了若干 serving 优化方向，包括低开销 tool calling、append-length-aware prefill、语义感知 tool 延迟预测以及 KV-cache 管理改进。
