#### Summary

#### Summary
In Gemma 4 31B's global attention layers, the value is the normalized key projection and the key is the value scaled by a fixed weight with RoPE applied to one quarter of its dimensions, creating an exact mathematical equivalence between the two. Existing serving engines still allocate full key and value tensors (1,024 values each), but a single 640-value row is sufficient to represent both. By exposing two overlapping strided views of this compact row, an unchanged paged attention kernel can read it as its key cache and value cache simultaneously. #### Summary
Expert parallelism in MoE models requires two synchronous collective communication steps per layer (dispatch and combine), and as compute throughput has outpaced interconnect bandwidth, these collectives have become a primary inference bottleneck. EchoMoE addresses this by using a hidden state from an earlier layer as a reference and communicating only the compressed difference between it and the current hidden state, periodically refreshing these references. The modification can retrofit existing MoE models with roughly 8,500x fewer training tokens than full pretraining. EchoMoE reduces inter-node communication volume by 58% and improves throughput by 22.6%, achieves up to 2.38x speedup over bandwidth-constrained Ethernet, and preserves average performance within 3.8 percentage points across 18 benchmarks, with no measurable quality loss when quantizing communicated representations.
