#### Summary
MoE inference on consumer hardware is bottlenecked by weight memory and SSD offloading latency: because layer N+1's expert selection depends on layer N's output, SSD reads cannot be prefetched early enough to overlap with compute. Edge0 introduces a prerouter—a lightweight per-layer head that predicts the next layer's routing one token ahead—and uses that prediction directly as the actual routing decision, enabling fully pipelined SSD prefetching. A recovery LoRA trained on the student execution path compensates quality loss from both INT4 quantization and routing replacement, bringing five-benchmark average performance close to the fp16 teacher. On a single 24GB machine, Edge0 serves a 35B MoE at 20tok/s within 3GiB of peak active memory, with the full framework, checkpoints, and adapters released as open source.

- 🎯 Prerouter predicts next-layer routing one token ahead, fully overlapping SSD prefetch with compute to eliminate offloading IO bottleneck
- 🔧 Recovery LoRA trained on the student path jointly compensates INT4 quantization loss and routing-replacement degradation
- 📊 35B MoE served at 20tok/s on a single 24GB machine with only 3GiB peak active memory, near fp16 teacher on five benchmarks
- 💡 Framework, checkpoints, and adapters are open source; supports both 8B and 35B model tiers

#### Summary
Weight-activation quantization is hindered by cross-layer transform propagation and architecture-specific optimization costs. MACaQ is a layer-local MXFP4 W4A4 post-training quantization method that applies a per-channel scale and block-Hadamard transform online to each linear layer's activations, absorbing the inverse transforms into weights, enabling a streaming single-layer-in-memory implementation with no cross-layer dependencies. Flip-Refinement, a Hessian-aware coordinate-descent procedure, greedily moves individual FP4 codes to adjacent representable values to improve over round-to-nearest. MACaQ adds only 2.3% end-to-end overhead over pure MXFP4 on Qwen3-32B in vLLM, achieves lower perplexity than DuQuant++ and MR-GPTQ, matches their best perplexity on Llama-3-8B in 11× less quantization time, and quantizes a 122B-parameter model in 64 minutes using only 32.5GB GPU RAM.

- 🎯 Layer-local design: online block-Hadamard transform + per-channel scale per linear layer, inverse absorbed into weights, no cross-layer dependencies
- 💡 Flip-Refinement: Hessian-aware coordinate descent greedily adjusting FP4 codes to adjacent representable values beyond round-to-nearest
- 📊 Only +2.3% end-to-end overhead over pure MXFP4 on Qwen3-32B (vLLM); 11× faster quantization than DuQuant++/MR-GPTQ on Llama-3-8B at equal PPL
- 🔧 122B-parameter model quantized in 64 minutes with only 32.5GB GPU RAM; vLLM-integrated, open-source
