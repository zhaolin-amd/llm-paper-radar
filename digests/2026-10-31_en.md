#### Summary
MoE inference on consumer hardware faces two barriers: a 35B model remains 19.5GB at INT4, and sparsity reduces compute but not memory footprint; naive SSD offloading fails because layer N+1's expert selection depends on layer N's output, preventing early reads. Edge0 introduces a prerouter—a lightweight per-layer head that predicts the next layer's expert routing one token ahead—so SSD prefetching fully overlaps with computation and no experts are dropped. A recovery LoRA trained on the student execution path compensates for quality loss from INT4 quantization and routing replacement. On a single 24GB GPU, Edge0 serves a 35B MoE at 20tok/s within 3GiB of peak active memory, staying within a few points of the fp16 teacher across five public benchmarks, with framework and checkpoints open-sourced.

- 🎯 Prerouter predicts next-layer expert routing one token ahead, enabling fully overlapped SSD async prefetch with zero expert drops
- 🎯 Recovery LoRA trained on the student path compensates accuracy loss from INT4 quantization and routing replacement
- 📊 35B MoE runs at 20tok/s on a single 24GB GPU with only 3GiB peak active memory, within a few points of fp16 teacher on 5 benchmarks
- 🔧 Framework, checkpoints, and adapters are fully open-sourced; 8B-tier models also supported on the same framework

#### Summary
Efficient edge inference for ternary LLMs such as BitNet b1.58 has been largely underexplored. Bitnet.cpp addresses this by introducing a dedicated inference system built around a novel mixed-precision GEMM (mpGEMM) library that enables sub-2-bits-per-weight, lossless inference. Two core kernels are proposed: Ternary Lookup Table (TL), which eliminates the spatial inefficiencies of prior bit-wise methods, and Int2 with a Scale (I2_S), which guarantees lossless output. Experiments show up to 6.25x speedup over full-precision baselines and up to 2.32x over low-bit baselines, with the system publicly released under Microsoft's official repository.

- 🎯 mpGEMM library with TL and I2_S kernels enables sub-2-bit, lossless ternary LLM inference on edge CPUs
- 📊 Up to 6.25x speedup vs. full-precision baselines; up to 2.32x vs. low-bit baselines
- 💡 TL addresses spatial inefficiency of bit-wise methods; I2_S guarantees bit-exact equivalence to original ternary model outputs
- 🔧 Targeting CPU edge deployment; open-sourced at Microsoft's official BitNet repository
