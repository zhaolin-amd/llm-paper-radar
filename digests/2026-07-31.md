### 2. ResKV: Reconstructing Omitted Attention Contributions for Fixed-Budget KV Cache Compression (9/10)
**arxiv** · `2607.29591` · 2026-07-31
👥 Yuhang Zhan, Lisi Chen, Shuo Shang · 🏷 cs.CL
🔗 [arXiv](https://arxiv.org/abs/2607.29591) · [alphaxiv](https://www.alphaxiv.org/abs/2607.29591)
📡 Sources: arxiv
🧪 kv_cache · KV cache eviction + residual reconstruction · cal: construction-time validation proxy，无需梯度更新 · perf: 保留 compressed decoding 的 peak memory 和 long-context decode throughput

#### 🧭 为什么推送这篇
**KV cache 压缩** · topic 5/5 · practicality 4/5 · composite 9/10 · ResKV 提出将 KV cache 分为 exact main cache 和 compact residual cache，通过在同一 softmax normalization 中同时恢复 numerator 和 denominator 的贡献来重建被 eviction 丢弃 token 的信息。方法在 LongBench 和 RULER 两个公认长上下文 benchmark 上验证，覆盖 query-aware 和 query-agnostic 设置以及多种 backbone 和 cache budget，属于核心 KV cache compression 工作。算法简洁（main cache + 紧凑 residual cache + 动态 gate），无需梯度训练，calibration 成本低，且明确保持了 peak memory 和 decode throughput，部署可行性较强，practicality 评为 4。

#### 摘要
KV cache eviction 方法会永久丢弃未选中 token 对 attention 的累积贡献，而 merging 方法虽保留更多信息但会扰动已保留的 key/value。ResKV 将固定 KV budget 划分为 exact main cache 和 compact residual cache，将被 eviction 丢弃 token 的贡献建模为 softmax attention 分子和分母上的 residual statistics，并让 main cache token 与 residual entry 参与同一 softmax normalization，从而同时恢复 numerator 和 denominator mass。在 LongBench 和 RULER 上的综合评估表明，相同 KV budget 下，ResKV 在 query-aware 和 query-agnostic 设置中均取得广泛提升，同时保持 peak memory 和 long-context decode throughput。

- 🎯 将 KV budget 分为 exact main cache 和 compact residual cache，residual cache 同时恢复 softmax numerator 和 denominator mass。
- 💡 construction-time validation proxy 决定每层每 KV head 的 residual 分配，decode-time dynamic gate 针对单个 query 动态调整 residual 贡献。
- 📊 在 LongBench 和 RULER 上覆盖多种 backbone、cache budget 及主流 compression baseline，相同 KV budget 下实现广泛提升。
- 🔧 保留 compressed decoding 的 peak memory 和 long-context decode throughput，不引入额外梯度训练。

#### 📎 相关方法 / 对比基线
- KV cache eviction — 永久丢弃未选中 token，ResKV 通过 residual cache 补偿其丢失贡献
- KV cache merging — 保留更多信息但扰动已保留 KV，ResKV 保持 main cache 精确不变
