#### Summary
MoE inference on consumer hardware is memory-bound: a 35B model requires 19.5GB at 4-bit, and sparsity reduces compute per token but not the bytes that must be loaded. Naive SSD offloading fails because the next layer's expert selection is unknown until the current layer finishes, making prefetch impossible. Edge0 introduces a prerouter—a per-layer lightweight head that predicts the next layer's routing one token ahead—so SSD reads can be fully pipelined behind compute with no expert dropping. A recovery LoRA trained on the student path compensates quality loss from both int4 quantization and routing replacement, yielding 20tok/s on a single 24GB GPU within 3GiB peak active memory, within a few points of the fp16 teacher across five public benchmarks.

- 🎯 Per-layer prerouter predicts next-layer expert routing one token ahead, enabling full SSD-prefetch/compute overlap with no dropped experts
- 💡 Recovery LoRA trained on the student execution path jointly compensates int4 quantization loss and routing replacement degradation
