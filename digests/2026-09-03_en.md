#### Summary
Long chain-of-thought reasoning makes the KV cache a critical memory bottleneck, and all existing KV cache compression methods rely on scoring tokens by estimated future importance to decide which to retain. Random Attention abandons scoring entirely: it preserves the full prompt and evicts tokens uniformly at random within each attention head for the reasoning trace. Across four models and six reasoning tasks, it matches the strongest prior evictor in accuracy while achieving 32–43% higher throughput in vLLM deployment. Controlled experiments show that the prompt is the fragile part of the cache, and reasoning traces are self-protected by redundancy at two levels—textual restatement and per-head copies—making random eviction sufficient once the prompt is kept intact.

#### Summary
KV cache size grows linearly with context length, creating severe memory bottlenecks for long-context LLM inference. SGD-KV introduces a head-aware compression framework that uses a chunk-summarization diagnostic task to systematically identify attention heads specialized in hierarchical information aggregation, then allocates KV cache budget proportionally to each head's summarization score. Evaluated on Qwen2.5-7B-1M and Qwen3-32B across diverse long-context benchmarks with contexts up to 1M tokens, SGD-KV achieves state-of-the-art performance while reducing KV cache memory usage by up to 75%.

- 💡 Explicit head-role differentiation via summarization scores outperforms simple heuristic-based compression baselines
