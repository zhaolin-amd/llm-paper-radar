#### Summary
In tool-augmented LLM agent settings, tool and skill schemas recur across requests in varying combinations and orders, preventing standard prefix caching from reusing their KV states. ReCache introduces resource-wise attention that removes cross-resource interactions and assigns resource-local positions, producing composition-invariant KV blocks that can be independently cached. It further restricts resource visibility via contribution-selected layer–KV-head-group routes and retains only invocation-critical fields through structural and semantic pruning. On a benchmark of seven tool- and skill-use datasets, resource-wise attention matches dense performance (82.3% vs. 82.4% Inv-F1) with a 3.655× time-to-first-token speedup; the full framework cuts allocated KV-tensor memory by 92.43% and accelerates attention by 1.423×.

- 🎯 Resource-wise attention removes cross-resource interactions and assigns resource-local positions, enabling composition-invariant KV block reuse
- 📊 3.655× TTFT speedup, 92.43% KV-tensor memory reduction, and 1.423× attention speedup with the full framework
- 📊 Resource-wise attention matches dense invocation performance: 82.3% vs. 82.4% Inv-F1
- 💡 Decouples reusable schema encoding from selective resource access via contribution-selected routing and structural/semantic pruning

#### 📎 Related methods / baselines
- prefix caching — fails when resource order/combination varies; ReCache overcomes this limitation

#### Summary
Autoregressive LLMs suffer from high inference latency due to sequential decoding; while speculative decoding alleviates this via parallel verification, existing approaches still use autoregressive drafting. DFlash introduces a lightweight block diffusion model as the draft model, generating draft tokens in a single forward pass and conditioning on context features extracted from the target model to achieve high acceptance rates. Experiments across multiple models and tasks demonstrate over 6x lossless speedup, with up to 2.5x higher throughput than the state-of-the-art method EAGLE-3.

- 🎯 Block diffusion model replaces autoregressive drafting, generating multiple draft tokens in one forward pass
