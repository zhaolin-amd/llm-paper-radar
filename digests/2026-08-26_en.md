#### Summary
KV cache memory fragmentation and redundant duplication in LLM serving severely limit batch sizes and throughput. PagedAttention adapts OS virtual memory and paging concepts to manage KV cache in non-contiguous fixed-size blocks, achieving near-zero memory waste and enabling flexible KV cache sharing within and across requests. Built on PagedAttention, vLLM delivers 2–4× higher throughput than FasterTransformer and Orca at the same latency level, with gains amplified for longer sequences, larger models, and more complex decoding algorithms.

- 🎯 PagedAttention partitions KV cache into non-contiguous fixed-size blocks, eliminating fragmentation and redundant duplication
- 📊 2–4× throughput improvement over FasterTransformer and Orca at equivalent latency
- 💡 Flexible KV cache sharing within and across requests reduces memory for beam search and parallel sampling
- 🔧 vLLM is open-source and deployed at scale in production

#### Summary
Agentic LLM pipelines accumulate context across retrieval, tool use, and multi-turn interactions, driving up inference latency; compressing inputs reduces this overhead but hurts accuracy, while standard speculative decoding (SD) cannot resolve the trade-off because it requires drafter and verifier to share identical context. AsymSpec removes this symmetry constraint: a lightweight drafter reads the full input and steers a large verifier that operates on a compressed view, coupled via contrastive δ-fusion of logits and a divergence-aware acceptance gate that maintains verification stability and high draft acceptance rates. Evaluated on four agentic capabilities and two end-to-end agent benchmarks, AsymSpec recovers ~90% of full-context accuracy on average, achieves 1.3–1.7× throughput speedups, and reduces compute to 0.2–0.3× of the full-context baseline on isolated text tasks.

- 🎯 Lightweight drafter reads full context; large verifier reads compressed context; coupled via contrastive δ-fusion and a divergence-aware acceptance gate
- 📊 ~90% of full-context accuracy on average; 1.3–1.7× throughput speedup; 0.2–0.3× compute cost on isolated text capabilities
- 💡 First framework extending speculative decoding to asymmetric-context settings, enabling simultaneous compression and lossless-style acceleration
- ⚠️ Requires drafter-verifier pairing; maximum tested model scale is not explicitly reported

#### Summary
