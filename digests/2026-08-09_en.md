#### Summary
PTQTP decomposes LLM weight matrices into two ternary planes with two free per-group scales; this work constrains the scale ratio to exactly 3, collapsing the decomposition into a known balanced-ternary nine-level uniform quantizer and losslessly folding the two trit planes into a single 4-bit code plane. This 4.0625-bits/weight block serves as a unified persistent representation across disk, expert cache, and kernel input, consumed in one integer dot pass with CPU-SIMD kernels. #### 🧭 Why this paper
**KV cache compression** · topic 4/5 · practicality 4/5 · composite 8/10 · RippleKV proposes a cross-layer KV cache budget allocation method based on perturbation propagation. It estimates the impact of value cache perturbations at each layer on the final output KL divergence over a calibration set to generate a sensitivity profile, enabling more principled allocation of a limited cache budget. The approach is conceptually clean, has low calibration cost (forward passes on a small calibration set), and is a post-hoc compression method requiring no model training. It is validated on LongBench with results superior to comparable baselines, making it a core contribution to the kv_cache bucket. Drawbacks include unknown maximum tested model scale and validation on only LongBench without downstream tasks such as MMLU/HellaSwag, which lowers topic_relevance to 4; end-to-end inference speedup is not reported, though the method is compatible with existing KV eviction frameworks, making deployment plausible.

#### Summary
Long-context LLM inference is memory-bottlenecked by KV cache, and existing cross-layer budget allocation methods rely on proxies—layer depth, attention statistics, or representation change—that fail to capture how per-layer perturbations propagate to the final output. RippleKV addresses this by injecting norm-adaptive perturbations into each layer's value cache over a small calibration set, measuring the induced KL divergence at the model output to build a model-specific sensitivity profile. The profile is converted into per-layer budget multipliers via normalization and exponential mapping, with a ratio parameter controlling allocation disparity between sensitive and tolerant layers. On LongBench, RippleKV achieves the highest average performance among all evaluated KV cache compression methods under matched cache budgets.

- 🎯 Injects norm-adaptive perturbations into each layer's value cache and measures output KL divergence to build a sensitivity profile
- 💡 Converts sensitivity scores to per-layer budget multipliers via normalization and exponential mapping, controlled by a ratio parameter
- 📊 Achieves highest average performance on LongBench among all compared KV cache compression methods at equal cache budgets
- ⚠️ Evaluated only on LongBench; no end-to-end latency or throughput numbers reported
