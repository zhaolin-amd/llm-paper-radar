#### Summary
Production LLM deployments frequently switch between model sizes for cascading, routing, or mid-conversation handoff, forcing the receiver to redo prefill from scratch each time. This work proposes cross-model KV cache transfer: a closed-form ridge mapper that linearly projects the source model's KV cache to the target model, skipping prefill. The design uses per-head top-k source-layer selection, RoPE stripping for position-free generalization, and calibration on only 500 FineWeb-Edu sequences of 1,024 tokens. Across six model pairs in three families, four pairs retain 73–98% of standalone-prefill accuracy with 2.7–25x prefill speedup; a nonlinear MLP recovers up to +37 pp HellaSwag retention on the two failing pairs.

#### Summary
Small language models are frequently recovered via knowledge distillation (KD), but the distillation training step itself is computationally expensive. Two systems contributions are presented: (1) offline KD caches the teacher's top-K logits once, eliminating the teacher from GPU memory while matching online distillation training loss, running ~29% faster per iteration and achieving up to 41% higher throughput on a single H200 GPU; (2) a fused chunked KL loss that never materializes the full vocabulary-sized logit tensor, keeping peak memory linear in sequence length and enabling training at 32,768 tokens on a single GPU. A separate toy benchmark confirms memory and iteration-rate scaling from 4K to 256K tokens.

- 🎯 Offline KD caches teacher top-K logits once, removing teacher from memory while matching online KD training loss
- 📊 ~29% faster per iteration and up to 41% higher throughput on a single H200 GPU vs. online KD
- 💡 Fused chunked KL loss keeps peak memory linear in sequence length, enabling 4× context (32,768 tokens) on one GPU
- 🔧 Toy benchmark validates memory and iteration-rate scaling from 4K to 256K tokens; implementation open-sourced
