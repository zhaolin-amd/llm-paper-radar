#### Summary
Autoregressive LLM inference is bottlenecked by sequential decoding, causing high latency and low GPU utilization. DFlash addresses this by replacing the autoregressive drafter in speculative decoding with a lightweight block diffusion model that generates draft tokens in a single forward pass, conditioned on context features extracted from the target model. This enables parallel drafting with high acceptance rates while maintaining lossless output quality. DFlash achieves over 6x lossless acceleration across various models and tasks, delivering up to 2.5x higher speedup than the state-of-the-art method EAGLE-3.

- 🎯 Method: block diffusion model replaces AR drafter, generating draft tokens in one forward pass conditioned on target-model context features
- 📊 Result: over 6x lossless acceleration across models and tasks; up to 2.5x speedup over EAGLE-3
- 💡 Novelty: first combination of parallel block diffusion with speculative decoding, eliminating sequential bottleneck in the drafting stage
