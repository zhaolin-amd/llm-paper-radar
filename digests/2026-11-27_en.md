#### Summary
Following the rise of ternary LLMs led by BitNet b1.58, efficient edge inference solutions remain scarce. Bitnet.cpp is an inference system built specifically for BitNet b1.58 and ternary LLMs, centered on a novel mixed-precision matrix multiplication (mpGEMM) library. The library provides two core kernels: Ternary Lookup Table (TL), which overcomes spatial inefficiencies of prior bit-wise methods, and Int2 with Scale (I2_S), which guarantees lossless inference, both enabling sub-2-bit-per-weight high-speed execution. Experiments show up to 6.25x speedup over full-precision baselines and up to 2.32x over low-bit baselines; the system is publicly available on GitHub.

#### Summary
LLM deployment is constrained by memory and compute requirements, while existing quantization schemes struggle to preserve accuracy below 1 bit per weight. LittleBit represents weights through low-rank latent matrix factorization followed by binarization of the resulting factors, targeting quantization rates as low as 0.1 BPW. To offset the severe information loss, it integrates a multi-scale compensation mechanism over row, column, and latent dimensions, together with Dual-SVID QAT initialization and Residual Compensation. At 0.1 BPW, LittleBit on Llama2-7B surpasses leading methods operating at 0.7 BPW, compresses Llama2-13B to under 0.9 GB (~31× memory reduction), and projects an 11.6× inference speedup over FP16.

- 🎯 Low-rank latent factorization + factor binarization enables quantization down to 0.1 BPW, with Dual-SVID QAT init and Residual Compensation to reduce approximation error
- 📊 0.1 BPW LittleBit on Llama2-7B outperforms leading methods at 0.7 BPW; Llama2-13B fits in <0.9 GB (~31× memory reduction)
- 💡 Multi-scale importance parameters learned across row, column, and latent dimensions compensate for extreme precision loss
- ⚠️ 11.6× speedup vs FP16 is a theoretical estimate, not measured end-to-end; QAT training cost is substantial
