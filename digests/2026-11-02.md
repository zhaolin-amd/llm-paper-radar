#### 摘要
现有 block-scaled LUT 量化格式（NF4、BOF4、NVFP4 等）依赖固定 grid，无法在所有 bit-width 下最优。SHq 提出一套 closed-form 的参数化 grid 族，通过 companding 强度 α（控制均匀到浮点式间距的插值）和非对称偏移 c（允许 FP8 block scale 的符号位选择 grid 或其镜像，最多使每 block 可用值翻倍）两个自由度来定义 grid。在 3B–35B 参数的五个模型（含 MoE）上，用 RTN 和 GPTQ 在 2–6 bit 评估，SHq 在 3 和 4 bit 的每个场景下均取得最低 KL divergence，比最优固定 grid 最高降低 34%，并将 NVFP4 的 KL divergence 降低 41–67%，同时提升下游精度。

- 🎯 SHq 通过 companding 强度 α 和偏移 c 两参数定义 closed-form LUT grid，可 drop-in 替换任何 block-scaled 格式的 grid
- 📊 在 3–4 bit 所有场景、2/5/6 bit 多数场景下取得最低 KL divergence，比最优固定 grid 最高降低 34%
- 📊 4.5 bit/weight 下，SHq 将 NVFP4 的 KL divergence 降低 41–67%，并提升下游精度
- 💡 FP8 block scale 的符号位用于选择 grid 与其镜像，最多使每 block 可用值翻倍，无额外推理开销

#### 摘要
大模型推理成本限制了 coding agent 的部署，量化是常见压缩手段，但其对 agent 行为的影响尚不清晰。本文对 Qwen2.5-Coder-Instruct（7B/14B/32B）和 Devstral-Small-2507（24B）在 OJBench 上系统对比 BF16 与 4-bit AWQ/GPTQ，跨三个随机种子评测。最终准确率无统计显著差异，但行为变化显著：AWQ 使 Qwen-7B one-shot 解题从 17 次降至 0，循环解题从 10 次升至 25；Devstral 的失败类型从运行时错误向错误答案和超时大幅偏移。结果表明，评估量化鲁棒性需超越 accuracy，覆盖解题轨迹、工具调用和失败模式。

- 🎯 对比 BF16 与 4-bit AWQ/GPTQ 在多个 coding agent 模型（7B–32B）上的行为差异，使用 OJBench 基准跨 3 个种子评测
- 📊 所有模型最终准确率无统计显著损失，但 AWQ 使 Qwen-7B one-shot 解题从 17 降至 0，循环解题从 10 升至 25
- 📊 Devstral 量化后失败类型显著从运行时错误转向错误答案和超时；Qwen-32B 编译错误在量化下略有上升
- 💡 提示量化鲁棒性评估应包含解题轨迹、工具调用模式和失败模式，而非仅看 accuracy
