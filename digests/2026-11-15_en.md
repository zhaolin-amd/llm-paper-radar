#### Summary
Running 35B-class MoE models on consumer hardware is memory-bound: 4-bit quantization still requires 19.5GB, and naive SSD offloading fails because layer N+1's expert selection depends on layer N's output, preventing early prefetching. Edge0 introduces a prerouter—a per-layer head that predicts the next layer's routing one token ahead and uses that prediction as the actual routing—enabling streaming expert prefetch that fully overlaps with compute. A recovery LoRA trained on the student path compensates for quality loss from both INT4 quantization and routing replacement. On a single 24GB machine, Edge0 serves a 35B MoE at 20tok/s within 3GiB of peak active memory, staying within a few points of the fp16 teacher across five public benchmarks.

- 🎯 Prerouter predicts next-layer routing one token ahead and replaces actual routing, enabling expert prefetch to overlap with current-layer compute

- 💡 Recovery LoRA trained on the student path jointly compensates for INT4 quantization loss and routing-replacement error
- 📊 Within a few points of fp16 teacher on five public benchmarks; framework, checkpoints, and adapters are open source

#### Summary
Weight-activation quantization incurs high calibration cost and architecture-specific cross-layer coupling in existing methods. MACaQ is an MXFP4 W4A4 post-training quantization scheme that processes each linear layer independently: it applies per-channel scaling and a block-Hadamard transform online to activations while absorbing the inverse transforms into weights, and uses Flip-Refinement—a Hessian-aware coordinate-descent procedure—to move individual FP4 codes to adjacent representable values beyond round-to-nearest. The layer-local design enables streaming quantization with only one layer in memory at a time, adds only 2.3% end-to-end overhead over pure MXFP4 on Qwen3-32B in vLLM, achieves lower perplexity than DuQuant++ and MR-GPTQ, and quantizes a 122B-parameter model in 64 minutes using 32.5GB GPU RAM.

- 🎯 Each linear layer processed independently via online block-Hadamard transform absorbed into weights, eliminating cross-layer dependencies and enabling streaming single-layer memory usage
- 💡 Flip-Refinement: Hessian-aware coordinate descent greedily shifts individual FP4 codes to adjacent representable values, improving over round-to-nearest
- 📊 Beats DuQuant++ and MR-GPTQ in perplexity; matches their best perplexity on Llama-3-8B in 11× less quantization time; only +2.3% end-to-end overhead on Qwen3-32B in vLLM
- 🔧 Quantizes a 122B-parameter model in 64 minutes with 32.5GB GPU RAM; generalizes to image diffusion models without architecture-specific changes
