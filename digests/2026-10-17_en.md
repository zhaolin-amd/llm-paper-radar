#### Summary

#### Summary
Efficient edge inference for ternary LLMs such as BitNet b1.58 has lacked systematic support. Bitnet.cpp addresses this by targeting mixed-precision matrix multiplication (mpGEMM), which dominates inference latency in ternary LLMs, via two novel kernels: Ternary Lookup Table (TL), which resolves spatial inefficiencies of bit-wise methods, and Int2 with a Scale (I2_S), which guarantees lossless inference. #### Summary
Long-context LLM inference is bottlenecked by peak memory during prompt prefill. Existing KV cache compression methods either require full-prompt prefill before eviction (preserving quality but maintaining high peak memory) or perform chunk-level online eviction (reducing peak memory but degrading cache quality due to incomplete context). TideKV introduces a layer-major delayed eviction architecture: within each Transformer layer, all prompt chunks are processed sequentially, full-prompt KV is retained only for the currently active layer, and eviction is performed at layer end—simultaneously preserving full-prompt-aware selection and reducing activation/temporary memory. On A100 at 64K, the construction-time transient memory footprint is reduced by 83.89%; on RTX 4090, TTFT increases by only 1.06% at 64K and 128K prefill becomes feasible; on Jetson, 128K prefill succeeds where matched post-prefill compression runs out of memory.

- 📊 Reduces construction-time transient memory footprint by 83.89% at 64K on A100; TTFT overhead only 1.06% at 64K on RTX 4090
- 📊 Enables 128K prefill on resource-constrained Jetson, where post-prefill compression runs out of memory
- 💡 Compatible with existing KV cache compression methods by changing eviction timing only, not the eviction algorithm itself
