#### Summary
Running 35B-class MoE models on consumer hardware is bottlenecked by weight memory: at 4-bit the model is 19.5GB, and SSD offloading alone fails because layer N+1's expert selection cannot be known before layer N finishes, preventing early I/O. Edge0 introduces a prerouter that predicts each layer's routing one token ahead, allowing SSD reads to overlap with compute, and trains a recovery LoRA on the student path to recover quality lost to INT4 quantization and routing replacement. On a single 24GB machine, Edge0 serves a 35B MoE at 20 tok/s within 3GiB of peak active memory, staying within a few points of the fp16 teacher across five public benchmarks.

- 🎯 Prerouter predicts the next layer's routing one token ahead, enabling SSD prefetch to hide behind compute and unblocking offloading
- 🔧 Recovery LoRA trained on the student path compensates for both INT4 quantization loss and routing-replacement error
- 📊 35B MoE runs at 20 tok/s on a single 24GB GPU + SSD with only 3GiB peak active memory
- 📊 Within a few benchmark points of the fp16 teacher on five public benchmarks; framework, checkpoints, and adapters are open source

#### Summary
Efficient edge inference for ternary LLMs such as BitNet b1.58 has remained underexplored despite growing interest in 1-bit LLMs. Bitnet.cpp targets the dominant compute bottleneck—mixed-precision matrix multiplication (mpGEMM)—with two complementary solutions: Ternary Lookup Table (TL), which overcomes spatial inefficiencies of bitwise methods, and Int2 with a Scale (I2_S), which guarantees lossless inference. On CPU edge devices, Bitnet.cpp achieves up to 6.25x speedup over full-precision baselines and up to 2.32x over low-bit baselines, and is publicly released.

- 🎯 TL and I2_S methods enable sub-2-bits-per-weight lossless mpGEMM for ternary LLMs on CPU
- 📊 Up to 6.25x speedup over full-precision baselines and up to 2.32x over low-bit baselines
- 💡 TL addresses spatial inefficiency of bitwise approaches; I2_S ensures lossless edge inference
- 🔧 Calibration-free, open-source inference system targeting CPU edge deployment
