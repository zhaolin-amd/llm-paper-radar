#### 🧭 为什么推送这篇
**KV cache 压缩** · topic 5/5 · practicality 4/5 · composite 9/10 · 本文提出一种基于可学习gate的KV cache eviction方法，在RULER和LongBench两个标准长上下文基准上验证了75%压缩率下Qwen3-8B的性能，分别仅下降3.72和1.36分，结果可信。方法核心是在softmax内部设计gate以保证质量守恒，理论分析充分。实用性方面，gate机制插入attention normalizer属于中等复杂度，不需要额外数据或大量标注，压缩率高，但需要一定训练开销且无端到端speedup数据，整体实用性评为4。最大测试模型为8B级别，但对kv_cache bucket不设7B门槛，故满足要求。

#### 摘要
KV cache eviction 需要判断哪些缓存条目可被丢弃而不影响信息完整性。本文提出在 softmax 归一化器内部放置可学习 gate，使每个条目的注意力权重受 gate 控制，并在语言建模 loss 上训练。理论分析揭示两个根本障碍：(1) 在冻结骨干网络下，密集注意力对应的 no-op 解是 gate 的最优解，gate 趋近常数而无法排序；(2) 梯度将冻结模型已有误差归咎于 gate，使训练信号污染。消除这两个障碍的方法是将密集注意力置于 gate 之外并以密集模型预测为目标，在此条件下，75% KV cache 压缩率下 Qwen3-8B 在 RULER（8K）达到 90.14，在 LongBench 达到 46.03，分别仅低于全缓存 3.72 和 1.36 分。

- 🎯 gate 置于 softmax 归一化器内部，确保压制一个条目时其权重质量转移给其他条目而非被丢弃
- 💡 揭示可学习 eviction 的两大根本障碍：冻结骨干偏向 no-op 解、梯度信号被已有模型误差污染
- 📊 75% KV cache 压缩率下 Qwen3-8B：RULER@8K 90.14（↓3.72）、LongBench 46.03（↓1.36）
- 💡 被丢弃的 KV 条目用参数无关的 centroid 在 softmax 内部恢复，优于任何外部 memory 读取

#### 摘要
