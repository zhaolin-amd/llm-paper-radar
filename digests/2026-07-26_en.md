#### Summary
KV cache memory in LLM serving suffers from severe fragmentation and redundant duplication, drastically limiting batch sizes and throughput. PagedAttention adapts classical OS virtual memory and paging techniques to manage KV cache in non-contiguous memory blocks, achieving near-zero memory waste and enabling flexible KV cache sharing within and across requests. Built on PagedAttention, vLLM delivers 2–4× higher throughput than state-of-the-art systems such as FasterTransformer and Orca at the same latency level, with gains amplified for longer sequences, larger models, and complex decoding algorithms.

- 🎯 PagedAttention manages KV cache in OS-style paged blocks, eliminating fragmentation and redundant duplication
- 📊 vLLM achieves 2–4× throughput improvement over FasterTransformer and Orca at equal latency
- 💡 Enables flexible intra- and inter-request KV cache sharing to further reduce memory footprint
- 🔧 Gains are more pronounced with longer sequences, larger models, and more complex decoding algorithms
