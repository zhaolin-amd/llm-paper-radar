#### Summary
KV cache memory in LLM serving grows dynamically per request and suffers from fragmentation and redundant duplication, severely limiting batch sizes and throughput. PagedAttention adapts OS virtual memory and paging concepts to partition KV cache into fixed-size, non-contiguous physical blocks, achieving near-zero memory waste and enabling flexible KV cache sharing within and across requests. vLLM, built on PagedAttention, delivers 2–4× higher throughput than state-of-the-art systems such as FasterTransformer and Orca at the same latency level, with larger gains for longer sequences, larger models, and more complex decoding algorithms.

- 🎯 PagedAttention maps KV cache to non-contiguous physical blocks, eliminating fragmentation and redundant duplication
- 📊 vLLM achieves 2–4× throughput improvement over FasterTransformer and Orca at equal latency
- 💡 Supports flexible KV cache sharing within and across requests to further reduce memory usage
- 🔧 Gains are more pronounced with longer sequences, larger models, and more complex decoding algorithms
